# Информация о полях

| Поле | Описание | Тип | Может ли быть пустым | Роль |
|---|---|---|---|---|
| Complaint ID | Уникальный идентификатор обращения | integer | Нет | Первичный ключ |
| Date received | Дата получения обращения | date | Нет | Анализ динамики |
| Product | Финансовый продукт | text | Нет | Сегментация |
| Sub-product | Подтип продукта | text | Да | Детализация |
| Issue | Проблема | text | Нет | Основная категория обращения |
| Sub-issue | Подпроблема | text | Да | Детализация обращения |
| Company | Компания | text | Нет | Анализ структуры обращений |
| State | Штат клиента | text | Да | Географический анализ |
| Submitted via | Канал обращения | text | Нет | Анализ каналов |
| Company response to consumer | Результат ответа | text | Да | Анализ реакции компании |
| Timely response? | Своевременен ли ответ | text | Нет | Метрика качества процесса |
