# financial-complaints-radar

Аналитический проект по исследованию клиентских проблем в финансовых продуктах на основе данных Consumer Financial Protection Bureau.

## Статус проекта

В разработке.

## Цель

Разработать аналитическую систему, которая помогает находить растущие категории клиентских обращений и определять направления для продуктового исследования.

## Данные

Источник: Consumer Complaint Database, CFPB.

Планируемый период анализа: 2024-2025 годы.

Направления:

- банковские карты;
- текущие и сберегательные счета;
- денежные переводы и платёжные сервисы.

Исходные данные не хранятся в репозитории, инструкция по их получению приложена отдельно.

## Планируемые инструменты

- SQL;
- PostgreSQL;
- Python;
- pandas;
- DataLens;
- Git

## План анализа

1. Проверка качества данных;
2. Исследование динамики обращений;
3. Анализ продуктов, проблем и подпроблем;
4. Анализ своевременности ответов;
5. Поиск аномальных всплесков;
6. Географический анализ;
7. Создание дашбордов;
8. Формулирование продуктовых рекомендаций.

## Ограничения

Количество обращений нельзя напрямую интерпретировать как качество компании без информации о числе её клиентов, операций и доле рынка.
